====================================================

ARRANCAR LA APP WEB (Streamlit)
---------------------------------

  1. Abrir la terminal

  2. Ir a la carpeta del proyecto:
     cd /Users/agustin/Desktop/Projects/YoutubeHelp/youtube_ai_manager

  3. Activar el entorno virtual:
     source venv/bin/activate

  4. Lanzar la app:
     streamlit run app.py

  5. Se abre automáticamente en el navegador en:
     http://localhost:8501

  Para cerrar la app: Ctrl + C en la terminal
  Para desactivar el venv: deactivate


====================================================
  BOT DE TELEGRAM (Automatización)
====================================================

  EL BOT ARRANCA SOLO — NO HAY QUE HACER NADA
  ---------------------------------------------
  El bot está configurado como servicio del sistema (launchd).
  Arranca automáticamente cuando iniciás sesión en la Mac
  y se reinicia solo si crashea. No necesitás abrir ninguna
  terminal para usarlo.

  Para confirmar que está activo, mandá en Telegram:
    /ping
  → Si responde, el bot está corriendo.


  VERIFICAR EL ESTADO:
  ---------------------
  Opción 1 — desde Telegram:
    /ping   → responde con la hora y el estado actual

  Opción 2 — desde la terminal:
    launchctl list | grep youtubebot
    → Si aparece un número (PID), está corriendo.
    → Si aparece un 0 o no aparece nada, está apagado.

  Ver el log en vivo:
    tail -f /tmp/youtubebot_error.log


  REINICIAR EL BOT (si algo falla):
  -----------------------------------
  launchctl stop com.youtubebot
  launchctl start com.youtubebot

  O en un solo comando:
  launchctl stop com.youtubebot && sleep 2 && launchctl start com.youtubebot


  APAGAR EL BOT DEFINITIVAMENTE:
  --------------------------------
  launchctl unload ~/Library/LaunchAgents/com.youtubebot.plist

  VOLVER A ACTIVARLO:
  launchctl load ~/Library/LaunchAgents/com.youtubebot.plist


  COMANDOS DEL BOT EN TELEGRAM:
  --------------------------------
  /trabajar   → Crear contenido (Texto, Imagen, Historia,
                compilaciones de TikTok)
  /texto      → Shorts con texto sobre video de fondo
  /imagen     → Reel de pregunta viral con imágenes
  /historia   → Historia de atención al público
  /eleccion   → Reel "¿Cuál elegís?" con 6 opciones numeradas
  /urls       → Compilar con URLs específicas de TikTok
  /stats      → Ver vistas/likes de los últimos 10 videos
  /estado     → Ver en qué paso quedó el proceso
  /cancelar   → Cancelar el proceso en curso
  /ping       → Verificar que el bot está vivo

  WORKFLOW AUTOMÁTICO:
  El bot sube un video solo, de lunes a viernes a las 18:00
  (hora Argentina), sin que hagas nada.

  SI EL BOT NO RESPONDE EN TELEGRAM:
  ------------------------------------
  1. Abrí una terminal
  2. Ejecutá: launchctl list | grep youtubebot
  3. Si no aparece: launchctl load ~/Library/LaunchAgents/com.youtubebot.plist
  4. Esperá 5 segundos y mandá /ping en Telegram


====================================================
  QUÉ HACE CADA MÓDULO
====================================================

  - Analizador de Canal
    Ve estadísticas de tu canal de YouTube + análisis con IA.
    Útil para entender qué videos funcionan mejor.

  - Tendencias Virales
    Busca temas que están en tendencia y los rankea con IA.
    Usalo para decidir sobre qué grabar.

  - Generador de Contenido
    Le das un tema y Claude te genera: guión completo,
    título, descripción y tags para el video.

  - Generador de Voz
    Convierte texto a voz en español usando ElevenLabs.
    Podés usar el guión generado directamente acá.

  - Subida a YouTube
    Sube el video terminado a tu canal directamente desde la app.
    Necesita el OAuth2 (ya configurado con client_secret.json).


====================================================
  SI ALGO NO FUNCIONA
====================================================

  - "No module found" → probablemente el venv no está activado.
    Volvé al paso 3 arriba.

  - Error de API key → revisá el archivo .env en la carpeta.
    Las keys son: ANTHROPIC_API_KEY, YOUTUBE_API_KEY,
    YOUTUBE_CHANNEL_ID, ELEVENLABS_API_KEY

  - Error de autenticación YouTube → el archivo client_secret.json
    tiene que estar en la raíz del proyecto. Si el token expiró,
    borrá token_youtube.json y volvé a autenticar.

  - Cuota de YouTube agotada → la API tiene 10,000 unidades/día.
    Esperá hasta mañana.

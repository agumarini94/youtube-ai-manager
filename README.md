# YouTube AI Manager

> Automate your YouTube channel with AI — find viral TikTok clips, compile them, generate SEO-optimized titles/descriptions/tags, create thumbnails, and publish to YouTube. All from Telegram or a Streamlit web UI.

Built with **Claude (Anthropic)**, **ElevenLabs**, **FFmpeg**, and the **YouTube Data API**.

---

## What it does

- **Telegram Bot** — full workflow from your phone: search clips → approve → compile → publish
- **Smart search** — by category, free text, or paste TikTok links directly
- **Country filter** — target content from Argentina, Mexico, Brazil, Colombia, Chile, Spain, USA, or global
- **Auto compilation** — downloads and merges clips with FFmpeg
- **AI-powered SEO** — title, description, and tags generated by Claude with visual video analysis
- **Auto thumbnail** — extracts the best frame and overlays AI-generated text
- **Smart scheduling** — publishes at peak audience hours, skips bad days automatically
- **Previous video linking** — each description auto-includes a link to the previous upload
- **Web dashboard** — Streamlit UI for configuration, history, SEO editing, and manual uploads

## Requirements

- Python 3.10+
- FFmpeg (`brew install ffmpeg` on Mac / `sudo apt install ffmpeg` on Linux)
- [Anthropic API key](https://console.anthropic.com) (Claude)
- YouTube channel with Google Cloud OAuth2 configured
- Telegram bot token (optional — for the automated workflow)
- [ElevenLabs API key](https://elevenlabs.io) (optional — for voice generation)

## Installation

```bash
# 1. Clone the repository
git clone https://github.com/agumarini94/youtube-ai-manager.git
cd youtube-ai-manager

# 2. Create virtual environment
python3 -m venv venv
source venv/bin/activate        # Mac/Linux
venv\Scripts\activate           # Windows

# 3. Install dependencies
pip install -r requirements.txt

# 4. Configure environment variables
cp .env.example .env
# Open .env and fill in your API keys

# 5a. Start the web app
streamlit run app.py

# 5b. Or start the Telegram bot (in a separate terminal)
python3 run_bot.py
```

---

## Environment variables

Copy `.env.example` to `.env` and fill in each value:

| Variable | Description |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API — [console.anthropic.com](https://console.anthropic.com) |
| `YOUTUBE_API_KEY` | YouTube Data API v3 — Google Cloud Console |
| `YOUTUBE_CLIENT_SECRETS_FILE` | Path to `client_secret.json` (default: `client_secret.json`) |
| `YOUTUBE_CHANNEL_ID` | Your channel ID (YouTube Studio → Settings → Channel info) |
| `YOUTUBE_TARGET_CHANNEL` | Your channel name (e.g. `ViralVideos`) |
| `ELEVENLABS_API_KEY` | ElevenLabs — optional, for voice generation |
| `ELEVENLABS_VOICE_ID` | ElevenLabs voice ID — optional |
| `TELEGRAM_TOKEN` | Bot token — [t.me/BotFather](https://t.me/BotFather) |
| `TELEGRAM_CHAT_ID` | Your Chat ID — [@userinfobot](https://t.me/userinfobot) |
| `HORA_AUTO` | Hour for daily auto workflow (default: `18`) |
| `MINUTO_AUTO` | Minute for daily auto workflow (default: `0`) |

## YouTube OAuth2 setup

To enable video uploads, create OAuth2 credentials in Google Cloud:

1. Go to [console.cloud.google.com](https://console.cloud.google.com) and create a project
2. Enable **YouTube Data API v3**
3. Go to **Credentials → Create Credentials → OAuth client ID**
4. Application type: **Desktop app**
5. Download the JSON and rename it to `client_secret.json` in the project root
6. In **OAuth consent screen**, add your email as a test user
7. In the Streamlit app (YouTube Upload tab), complete the OAuth flow

## Telegram bot setup

1. Chat with [@BotFather](https://t.me/BotFather) → `/newbot` → copy the token
2. Chat with [@userinfobot](https://t.me/userinfobot) → copy your Chat ID
3. Paste both into `.env`
4. Run `python3 run_bot.py`

### Bot commands

| Command | Description |
|---|---|
| `/trabajar` | Start the full workflow |
| `/urls <url1> <url2>` | Use specific TikTok URLs |
| `/estado` | Check current process status |
| `/cancelar` | Cancel the current process |

### Bot workflow

```
/trabajar
  → Format? (YouTube Video / Reel)
  → What to search? (category / free text / paste links)
  → Which country?
  → Searches and filters TikTok clips
  → You approve the clips
  → Compilation with real-time progress
  → Preview: video + thumbnail + SEO
  → Scheduled publish time (today if it's a good day)
  → Uploads to YouTube with thumbnail
```
